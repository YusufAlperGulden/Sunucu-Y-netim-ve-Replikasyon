Release Notes

Use this page as your guide to stay up to date on the latest enhancements and changes, ensuring you can make the most of ClusterControl's powerful capabilities.

v1.6.5

What's New

  • ClusterControl 5-Step Deploy / Import PostgreSQL Streaming Cluster Wizard: Added the complete interactive cluster deployment wizard with 5-step stepper navigation (Cluster details, SSH configuration with interactive user tooltips, user key path, custom SSH port, password visibility toggle and OS elevation radio selectors sudo, doas, pbrun, Node configuration with PostgreSQL version selection, Add nodes with 1-click Live PostgreSQL & Demo SSH credentials autofill, and Deployment preview).
  • One-Click Live Cloud Testing Credentials: Added instant Autofill support for Frankfurt Primary and London Standby live cloud PostgreSQL servers with simulated SSH credentials, enabling comprehensive end-to-end cluster deployment testing without requiring external physical server infrastructure.

v1.6.4

What's New

  • ClusterControl Team Details Information Modal: Clicking any team name in the User Management Teams table opens the full Team Details modal with user counts, member avatar badges, group permissions breakdown, and complete cluster permission access levels.
  • 3-State Table Header Sorting: Implemented interactive 3-state sorting (Ascending → Descending → Cancel sorting) across table column headers with visual direction arrows (▲, ▼, ⇅) and real-time hover tooltips.

v1.6.3

What's New

  • ClusterControl 4-Step Create Team Wizard: Added the complete interactive team creation wizard with step-by-step navigation (Details configuration, Users multi-select tag and search selector with team migration warnings, Permissions toggles for controller settings & cluster permission levels Manage, View, No access, Custom, and Preview summary).
  • Teams Management Table Sync: The Teams tab in User Management dynamically lists team names, owners, creation timestamps, and action buttons synced with PostgreSQL.
  • Automatic Member Assignment & User Wizard Integration: Selected users are automatically reassigned to the new team, and new teams are instantly added to the Create User wizard dropdown.

v1.6.2

What's New

  • ClusterControl 3-Step Create User Wizard: Added the complete interactive user creation wizard with step-by-step navigation (Details, Team group selection from admins, nobody, users, and Preview summary).
  • Real-time User Table Updates: Newly created users are immediately persisted to PostgreSQL with full team metadata, encrypted credentials, and dynamically rendered into the User Management table upon creation.

v1.6.1

Release cycle

We highly advise you to keep up to date with the latest version for the following reasons:

  • ClusterControl has a short release cycle compared to other software applications (likely a new major release every quarter of the year).
  • ClusterControl has to keep up with all the latest changes and modifications introduced by supported database and application vendors.
  • Some of the issues you have encountered may already be fixed in the latest weekly maintenance or major release.

What's New

  • User Management Table Sync Fix: Fixed table DOM targeting (users-tbody) so the active Admin profile (admin@localhost, UTC timezone, Admins team) loads and renders immediately across all router navigation flows.
  • ClusterControl Settings Complete 7-Tab Alignment: Fully aligned all Settings tabs with the official ClusterControl website:
    • Cloud storage credentials: 4-provider interactive wizard (Amazon Web Services, Google Cloud, Microsoft Azure, S3 Compatible) with official provider landing links and credentials upload support.
    • Notification services: Aligned table headers (Name, Service, Active, Send Alarms From, Trigger events) and empty state illustration.
    • Certificate management: Full directory hierarchy (galera, group_replication, mssql_ao_async, mssql_single, postgresql_single, redis_sharded, replication, valkey_sharded) with folder creation and cert management.
    • License: ClusterControl Enterprise license status (Severalnines AB, 2027-06-24, 23/25 nodes limit progress indicator) and key activation.
    • Addons: Ops-Center (multi-CMON controller scaling) and Kubernetes database operator modules with toggles and documentation links.
    • Diagnostics: UI Audit data collection recording with downloadable diagnostic logs.

v1.6.0

Release cycle

We highly advise you to keep up to date with the latest version for the following reasons:

  • ClusterControl has a short release cycle compared to other software applications (likely a new major release every quarter of the year).
  • ClusterControl has to keep up with all the latest changes and modifications introduced by supported database and application vendors.
  • Some of the issues you have encountered may already be fixed in the latest weekly maintenance or major release.

What's New

  • Core Fix (Persistent Auth & Instant Nodes View Loading): Doğrudan #nodes-view veya sol menüdeki Nodes sekmesine geçildiğinde yaşanan takılma/sonsuz yüklenme (infinite loading) sorunu çözüldü. Kimlik doğrulama belirteci (globalAuthToken) kalıcı olarak localStorage ile ilişkilendirildi ve tüm direkt sayfa geçişlerinin anında yüklenmesi sağlandı.

v1.5.9

  • Visual Dynamic (Smaller & Fast-Paced Floating Particles): Giriş ekranındaki baloncuklar kompakt boyutlara (15px - 60px yarıçap) çekildi, adetleri 65'e yükseltildi ve hareket hızları artırılarak ekran üzerinde canlı, hızlı ve enerjik süzülmeleri sağlandı.

v1.5.8

  • Visual Dynamic (Extra Large & Faster Floating Bubbles): Giriş ekranındaki (Login screen) baloncuklar ekstra büyük boyutlara (180px - 460px yarıçap / 360px - 920px çap) yükseltildi ve hareket hızı ~4 kat artırılarak ekran üzerinde daha akıcı ve dinamik yüzmeleri sağlandı.

v1.5.7

  • UI/UX (Cluster Alarms Table Structure): Cluster Detay altındaki Alarms sekmesi ClusterControl ile birebir uyumlu tam tablo yapısına kavuşturuldu. "Title", "Severity", "Category", "Cluster", "Hostname", "When", "Actions" sütun başlıkları ve standart boş durum (You haven't received alarms yet. When you do, it'll show up here.) entegre edildi.

v1.5.6

  • Feature (Backups Folders & Solid White Modals): Backups sayfasına ClusterControl standardında iki klasör sekmesi eklendi: All Backups (No backups created yet.) ve Schedules (No schedules created yet.). Ayrıca yedekleme sihirbazı ve seçim pencerelerinin arka planı şeffaf/gri görünümden arındırılarak saf beyaz (solid white) kurumsal modal tasarımına dönüştürüldü.

v1.5.5

  • Visual Design (Larger Floating Bubbles): Giriş ekranındaki (Login screen) hareketli baloncuklar (floating bubbles) daha büyük, canlı ve estetik boyutlara yükseltildi (120px - 340px yarıçap). Yumuşak geçişler ve şeffaf katman efektleri uygulandı.

v1.5.4

  • Major Feature (Cluster Performance Module): ClusterControl ile birebir uyumlu Performance sekmesi entegre edildi. DB Status (Canlı durum değişkenleri karşılaştırması), DB Growth (Depolama & Hacim analitiği), DB Variables (Aranabilir konfigürasyon değişkenleri), Query Monitor (Canlı aktif SQL sorguları), Query Monitor/Agents (Ajan yönetimi), Advisors (Otomatik sağlık danışmanları), Schema Analyzer (Tablo ve sütun yapısı analizi) ve Transaction Deadlocks (Kilitlenme tespiti) alt sekmeleri aktif hale getirildi.

v1.5.3

  • Core Fix (Strict Cluster Dashboard Isolation): Sunucu Yönetim Dashboard telemetri döngüsü (fetchDashboardMetrics) tamamen yeniden yazıldı. Artık Araç Plaka Takip Sistemi açıldığında yalnızca Araç Plaka'nın 2 sunucusu; E-mail Okuma Programı açıldığında ise yalnızca E-mail Okuma Programı'nın 2 sunucusu gösterilir. Diğer tüm cluster'lara ait eski veya yabancı kartlar container'dan anında temizlenir.

v1.5.2

  • Improvement (Cluster Metric Table Dynamic Mapping): Her cluster için takip edilen ana tablo ayrıştırıldı. Araç Plaka Takip Sistemi için vehicles tablosu (6 Araç (vehicles)), E-mail Okuma Programı için ise PostgreSQL üzerindeki canlı emails tablosu (3 E-posta (emails)) otomatik sorgulanarak ekrana canlı ve doğru şekilde yansıtıldı.

v1.5.1

  • Fix (Cluster Switch & Telemetry Reset): E-mail Okuma Programı ve Araç Plaka Takip Sistemi gibi farklı cluster'lar arasında geçiş yapılırken metrik kartlarının karışması ve eski kümenin kartlarının ekranda kalması sorunu hash normalizasyonu ve tam DOM temizliği (DOM wipe & fresh reload) ile giderildi. Her cluster kendi başlığı (örn: E-MAIL OKUMA PROGRAMI) ve kendi sunucuları ile anında yüklenir.

v1.5.0

  • UI/UX (Dynamic CPU/RAM Visibility): Sunucu Yönetim Dashboard ekranında, Linux VPS / SSH yapılandırması olmayan sunucularda N/A gösteren CPU ve RAM kartları otomatik olarak tamamen gizlendi. Yalnızca gerçek SSH/OS metrikleri mevcut olduğunda kartlar görünür hale getirilir; böylece arayüz gereksiz N/A kutucuklarından arındırılmış temiz bir görünüme kavuşturuldu.

v1.4.9

Artık her cluster'ın Dashboard sekmesinde yalnızca o cluster'a ait sunucu düğümleri (Primary & Standby) gösterilir. Ayrıca breadcrumb navigasyonu (Project Name (ID: X)) dinamikleştirildi.

v1.4.8

  • Feature (User Management - Teams Tab): User Management ekranına Teams sekmesi tablosu eklendi. "Name", "Owner", "Created", "Actions" sütun başlıkları ve standart boş durum mesajı (No teams created yet.) eklendi.

v1.4.7

  • Fix (Cluster Detail Nodes Tab): Cluster Detay sayfasındaki Nodes sekmesinde düğüm sayısı kartlarının 0 olarak görünmesine sebep olan DOM ID çakışması giderildi (cluster-stat-*). Artık seçili cluster'a ait tüm düğümler anında Operational: 2, All: 2 vb. olarak dinamik şekilde kartlara yansıtılmaktadır.

v1.4.6

Canlı Render API doğrulaması tamamlandı.

Manage several ClusterControl controllers from one console. Ops-Center gives you a single pane of glass to monitor and operate every controller, cluster and node.

  • You run more than one ClusterControl controller — for example separate prod, staging or per-region installations — and want to manage them from one place.
  • Your fleet grows beyond ~1000 nodes and you need to scale out horizontally across several CMON controllers.
